# MIA MAYS — фанатский сайт

Статический сайт без сборки: HTML + `style.css` + `app.js` (чистый JS). Все ссылки относительные — работает в подпапке `/mia-mays-site/`.

## Страницы
- `index.html` — вступление: портрет MIA в рамке, реплики с печатью, звук по желанию, кнопка «Войти в дом» (анимация домиков и дверей), «Пропустить». Внизу экрана — деревня домиков.
- `home.html` — дом: порог, бегущая строка, настроения, дневник «Сегодня Мия…», бенто, счётчики, комнаты-двери, отсчёт.
- `story.html` — профиль, характер, страницы дневника, путь, комикс.
- `gallery.html` — фильтры, лайтбокс (стрелки, клавиатура), наклон.
- `cozy-night.html` — отсчёт, программа, правила, запись (localStorage).
- `shop.html` — макет «скоро», бесплатные обои и стикеры.
- `fans.html` — аватарка, мемы и гифки, примерка, игры, стена фанатов.
- `about.html` — вопросы, правила, о проекте.

## Локально
`python3 -m http.server` в этой папке.
