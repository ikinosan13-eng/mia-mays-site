# MIA MAYS — фанатский сайт (статичный, без сборки)

Сайт переводится на многостраничную структуру постранично.

## Файлы
- `index.html` — главная «Порог»: интерактивная комната (параллакс, портрет-дверь, сердечки по клику, лампа — ночной режим, звук), бегущая строка, приветствие, «комнаты»-двери, отсчёт до Уютной ночи с отметкой «Я приду» (localStorage).
- `app.js` — скрипт новых страниц (безопасен на страницах без нужных элементов).
- `style.css` — общие стили; стили главной — в блоке `body.home`.
- `old.html` + `old.js` — прежняя одностраничная версия (временно, не в меню; двери ведут на её разделы, будет разбита на страницы).
- `img/` — только: mia-pillow.jpg, mia-pajama-pillow.jpg, mia-pajama-crop.png, face-pillow.png, face-pajama2.png, face-pajama.png.

Все ссылки относительные (сайт работает из подпапки GitHub Pages).
