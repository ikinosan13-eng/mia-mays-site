# MIA_MAYS — план развития (T3)

## Цели
- Сделать сайт «живым» и уютным: плавные анимации, мягкая физика, тихий звук — без потери доступности и скорости.
- Сохранить статичность: GitHub Pages, без сборки, vanilla JS, файлы `index.html`, `style.css`, `app.js`.
- Использовать только существующие изображения из `img/` (уютные худи/пижама, полностью одетая, wholesome). Новых картинок не создавать.
- Никакой коммерции/авторизации на GitHub Pages: магазин остаётся макетом.
- Уважать `prefers-reduced-motion`, клавиатурную навигацию, адаптивность.

## Tier 1 — обязательно в этом проходе

| # | Задача | Критерии приёмки | Файлы |

| 1.2 | Параллакс в hero (transform, rAF, только при скролле в зоне hero) | Изображение/свечение смещаются с разной скоростью; при reduced-motion отключено; без layout-thrash | `index.html` (`.parallax` обёртки, `data-depth`), `app.js`, `style.css` |
| 1.3 | Тихие hover-звуки через WebAudio (синтез, без файлов) | Выключены по умолчанию; видимая кнопка 🔇/🔊 в шапке (`aria-pressed`); состояние в `localStorage`; AudioContext создаётся только по жесту пользователя; громкость ≈0.03 | `index.html` (кнопка), `app.js` (модуль Sound), `style.css` |
| 1.4 | Микро-анимации кнопок (bounce при клике, glow при hover/focus) | `.btn`, `.chip` пружинят; glow на hover и `:focus-visible`; отключено при reduced-motion | `style.css`, `app.js` (класс `.pop`) |
| 1.5 | Hover-эффекты карточек/сеток (подъём, мягкий наклон, блик) | `.card`, `.item`, `.panel`, `.g` реагируют на hover; на тач-устройствах ничего не ломается | `style.css` |
| 1.6 | Модалки с анимацией открытия/закрытия, focus-trap, Esc | Лайтбокс открывается с scale/fade, закрывается анимированно; Tab зациклен внутри; Esc и клик по фону закрывают; фокус возвращается; добавлена модалка «Coming soon» для магазина; навигация ←/→ в лайтбоксе | `index.html` (`#shopModal`, стрелки), `app.js` (универсальный `Modal`), `style.css` |
| 1.7 | Анимированный обратный отсчёт (flip/roll цифр) | Д/Ч/М/С отдельными цифрами; изменившаяся цифра «прокручивается»; screen reader получает текст раз в минуту, а не каждую секунду | `index.html` (`#countdown`), `app.js`, `style.css` |
| 1.8 | Физика сердечек в игре: гравитация, скорость, покачивание, delta-time | Движение одинаково при 60/120 Гц; сердечки ускоряются, качаются; подушка движется плавно (lerp); есть «искорки» при ловле; логика очков/рекорда сохранена | `app.js` |
| 1.9 | Физика фоновых сердечек (rAF + dt, ветер, покачивание) | Не более ~18 частиц, пауза при скрытой вкладке; отключено при reduced-motion | `app.js`, `style.css` (`.petal`) |
| 1.10 | Анимированная вставка нового поста на фан-стену | Новый пост «выпрыгивает» (scale/rotate), остальные не перерисовываются заново; данные в `localStorage` как прежде | `app.js`, `style.css` |

Общие критерии: `node --check app.js` без ошибок; все ассеты отдают 200; существующие функции (стикеры, GIF Factory → WebM, Try-on, Meme Maker, лазер, игра, отсчёт, галерея, фан-стена, мобильное меню) работают.
